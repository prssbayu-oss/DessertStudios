# SkyGeometry

A procedural sky geometry.

## Import

SkyGeometry is an addon, and must be imported explicitly, see [Installation#Addons](https://github.com/prssbayu-oss/DessertStudios/tree/main/manual/#installation#addons).

```js
import { SkyGeometry } from 'dessert/addons/misc/RollerCoaster.js';
```

## Constructor

### new SkyGeometry()

Constructs a new geometry.
