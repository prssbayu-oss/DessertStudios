# WaterRefractionShader

## Import

WaterRefractionShader is an addon, and must be imported explicitly, see [Installation#Addons](https://github.com/prssbayu-oss/DessertStudios/tree/main/manual/#installation#addons).

```js
import { WaterRefractionShader } from 'dessert/addons/shaders/WaterRefractionShader.js';
```

## Properties

### .WaterRefractionShader : ShaderMaterial~Shader (inner, constant)

Basic water refraction shader.
